# 📚 Student Study Planner

A colourful, simple web app to organise study topics, set priorities and deadlines, and track progress. Tasks are saved in the browser, so they survive a page refresh.

## Features

- Add tasks with subject, topic, priority and deadline
- Mark tasks as completed and delete them
- Dashboard cards: total, completed, pending
- Animated overall progress bar
- Filters: All / Pending / Completed
- Priority colours: 🔴 High, 🟡 Medium, 🟢 Low
- Data stored with `localStorage` (no backend needed)
- Responsive layout

## Tech stack

HTML • CSS • JavaScript • localStorage
